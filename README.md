# Light-Line Rotation Lab

Interactive companion to the paper:

> M. Madhi, *Special relativity: a geometric representation by rotation about the light line* (2026).

**Open the lab:** https://mmj50.github.io/light-line-lab

## What it is

The paper does special-relativistic kinematics with one hand-drawn right triangle and one rule:

- multiply V + A∥ by the Doppler factor k,
- divide V − A∥ by k,
- leave the perpendicular momentum A⊥ unchanged.

This page runs that rule live in the browser, section by section, and checks every result against the full Lorentz transformation.

## Use

Open `index.html` in any modern browser. It is a single self-contained file with no dependencies; only the web fonts load from the internet, and it works without them.
